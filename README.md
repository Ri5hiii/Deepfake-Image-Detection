# 🛡️ AI-Based DeepFake Image Detection System

An AI-powered DeepFake Image Detection System developed using **EfficientNet-B4** and **Grad-CAM** to identify AI-generated images and provide visual explanations for predictions. The project aims to improve digital media authenticity by detecting manipulated images generated by modern AI models.

---

## 📌 Project Overview

With the rapid growth of AI image generation technologies, verifying the authenticity of digital images has become increasingly important. This project uses deep learning to classify images as **Real** or **AI-Generated** while providing explainable AI (XAI) visualizations using Grad-CAM.

---

## 🚀 Features

- Detects Real and AI-Generated Images
- EfficientNet-B4 Transfer Learning Model
- Grad-CAM Heatmap Visualization
- Face Region Risk Analysis
- Confidence Score Prediction
- Interactive Streamlit Web Application
- Real-Time Image Classification
- User-Friendly Interface

---

## 🏗️ Model Architecture

- EfficientNet-B4 Backbone
- Transfer Learning
- Binary Classification
- Grad-CAM Explainability
- AdamW Optimizer
- Cosine Annealing Learning Rate Scheduler
- Mixed Precision (AMP) Training

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/Rishiii/DeepFake-Image-Detection.git
```

Move into the project directory

```bash
cd DeepFake-Image-Detection
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
